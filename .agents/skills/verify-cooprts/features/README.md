# CoopRTS verification feature map

Read `../SKILL.md` first and select proof by changed behavior. Default to a targeted development check; the matrix lists available proof layers, not mandatory per-change suites. Broad milestone/release acceptance is separately scheduled. Commands assume `V`, `LOGIC_RUN` and desktop `RUN` from that file; keep logic and launch directories separate. Capture labels must be unique. Use an inspected current view for desktop coordinates; sample fractions are not stable selectors.

Gameplay source paths above are under `Source/CoopRTS/` unless otherwise specified. A milestone/release baseline selects mapped scenarios once each in fresh worlds, plus relevant native/sockets layers; it is not an automatic per-change matrix. Existing `combat`, `orders`, `movement`, `match-*`, `doctrine-*` use controlled actors for specific assertions and must not be mistaken for freshly constructed player squads or complete network play. Authoritative standalone tests do not prove independent replication or a human's ability to judge strategic tradeoffs.
