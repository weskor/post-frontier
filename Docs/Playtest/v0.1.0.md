# Post-Frontier v0.1.0 — Linux friends prerelease

A development playtest for Linux x86_64 with a Vulkan-capable GPU and driver. This uses **Steam Spacewar App ID 480**, not a Steam store release. Steam may display the development identity Spacewar.

**WAN / real cross-account Steam joining remains unverified until humans try it.** This prerelease is for friends testing, not a claim of verified Internet multiplayer.

## Install

Download the pinned installer, then run it (no sudo):

```bash
curl --fail --show-error --location --proto '=https' --proto-redir '=https' \
  --output install.sh https://github.com/weskor/post-frontier/releases/download/v0.1.0/install.sh
bash install.sh
```

Run the second command only if the download succeeded; you can inspect `install.sh` first. The installer requires Bash, curl, tar and standard Linux core utilities; it does not install dependencies or modify shell profiles. It downloads the archive and `SHA256SUMS` over HTTPS and verifies the archive before installing.

Data goes in `${XDG_DATA_HOME:-$HOME/.local/share}/post-frontier/0.1.0`. The launcher is `~/.local/bin/post-frontier`; run that full path if `~/.local/bin` is not on your PATH. Arguments are passed through to the packaged `PLAYTEST.sh`.

Repeated installs retain an existing v0.1.0 installation, including saves, and refresh the launcher. They do not repair or overwrite an existing installation. Failed download/checksum verification leaves the existing installation and launcher untouched. No saves are deleted.

## Play with friends

1. Everyone installs this same version and runs the Steam desktop client, logged into **distinct Steam friends accounts**. Enable Steam's in-game overlay.
2. Run `~/.local/bin/post-frontier` (not Spacewar itself).
3. The host chooses **Host co-op**, then **Invite friends** from the match menu. Friends accept the invite or choose **Join Game** on the host in Steam's friends list.
4. Up to **five players including the host**; the host must remain running.

See [current controls](../../README.md#controls-in-current-source), the installed `PLAYTEST.txt` for launcher/Steam setup and log locations, and [feedback questions](1b-questions.md). Report the release version, what happened, and game logs; no automatic feedback upload is provided.

## Release assets

The release at [v0.1.0](https://github.com/weskor/post-frontier/releases/tag/v0.1.0) uses these exact names:

- `Post-Frontier-0.1.0-linux-x86_64.tar.gz`
- `SHA256SUMS` (SHA-256 manifest containing the archive's exact filename)
- `install.sh`

The archive is the existing `./x package --playtest` output, renamed for this release without changing its contents: one commit-named top-level directory containing `PLAYTEST.sh`, `PLAYTEST.txt`, and the complete packaged game. The installer uses that launcher rather than a separate game launch implementation. Checksums detect corruption; they are not an independent signature of publisher identity.
