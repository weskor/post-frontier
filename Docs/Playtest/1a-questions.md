# Step 1a playtest feedback

Gate: [steering and readability](../Design/build-order.md). Answer independently after each match; short answers are enough.

- **Match:** package commit, your player name, number of players, win/loss. Were you hosting?
- **Steering:** could you select the forces you wanted and make them move, attack or retreat? Rate clarity **1–5** (1 = confusing, 5 = clear). Name one order that did something you did not expect, if any.
- **JEV:** could you tell what JEV was planning and where the threat would arrive? Rate readability **1–5**. What cue helped, or what information was missing?
- **Awareness:** did you notice important wins, incoming threats and the match ending in time to react? Which event did you miss, if any?
- **Co-op:** could you tell what your teammates needed and coordinate with them? Describe a useful or confusing ping.
- **Confusion:** what was the most confusing moment? What one change would have helped most?

Include approximate match time and region for examples. Send these answers with the host's match JSON and any crash report or available logs using the package's `PLAYTEST.txt`; do not post logs publicly without checking them for personal information.
